# Apple Design & Impeccable Taste Rules

## Typography
- Strict hierarchy using variable weights (`font-medium` vs `font-semibold`), tight tracking on large headings.
- Always `antialiased` text.

## Layout
- Generous whitespace; let content breathe. Consistent spacing scale.

## Surfaces
- Restrained glassmorphism: `backdrop-blur-xl bg-slate-900/60` with clear, subtle borders.
- High-contrast text for readability on translucent layers.

## Polish
- Restraint over flashiness. Consistent radii, shadows and alignment.
- Details (hover, focus, disabled, empty, loading states) are designed, not defaults.
